# 🚀 CryptoChain - Blockchain Cryptocurrency Project

A complete blockchain implementation with cryptocurrency features, built with Go backend and modern web frontend.

## ✨ Features

### 🔗 Blockchain Core
- Proof of Work consensus algorithm
- SHA-256 cryptographic hashing
- Transaction validation and mining rewards
- Wallet system with public/private key cryptography
- Real-time block explorer

### 💰 Cryptocurrency Features
- Native token: CTC (CryptoChain Token)
- Wallet creation and management
- Send/receive transactions
- Mining with rewards (1 CTC per block)
- Transaction history

### 🎨 Modern Interface
- Real-time dashboard with live updates
- Animated blockchain visualization
- Responsive design
- Dark theme with neon accents
- Interactive modals and notifications

## 🛠️ Tech Stack

### Backend
- **Go** - High-performance blockchain engine
- **Gorilla Mux** - HTTP routing
- **ECDSA** - Elliptic curve cryptography for wallets

### Frontend
- **HTML5/CSS3** - Modern, responsive interface
- **Vanilla JavaScript** - No framework dependency
- **Font Awesome** - Icons
- **Google Fonts** - Typography
